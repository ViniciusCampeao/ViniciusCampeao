# Olá, eu sou o Vinícius 👋

Estudante de **Sistemas de Informação na UTFPR** e desenvolvedor **full-stack + maker**.
Gosto de resolver problemas reais de ponta a ponta — do firmware no microcontrolador
ao front-end no navegador, passando pelo servidor e pela infra que sustenta tudo.

- 🧩 **Full-stack**: React · TypeScript · Node · Python · Spring Boot
- 🔌 **IoT / Hardware**: ESP32, telas touch (CYD), integrações com APIs (Pix/Mercado Pago)
- 🖥️ **Infra self-hosted**: Docker, Prometheus/Grafana, VPS, CI/CD
- ♿ **Tecnologia assistiva**: pranchas de Comunicação Alternativa (CAA) usadas por famílias reais
